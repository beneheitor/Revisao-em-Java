🚀- Resolvendo exercícios para treinar lógica em Java.

1️⃣ - O primeiro exercício o desafio foi apenas mostrar um "Bom dia, pessoal". 
 Utilizei Arrays e estrutura de repetição com o for para ficar mais divertido.

2️⃣ - No segundo foi passado para fazer um algoritmo que solicitasse o nome do usuário.
 Utilizei Scanner para entrada de dados como o nome do usuário.
 
3️⃣ - O terceiro desafio o intuito era criar um algoritmo que solicitasse o nome e idade do usuários e exibisse com uma saudação.
 Utilizei Scanner para entrada de dados do nome e da idade do usuário e printei a saudação.
 
4️⃣ - O quarto desafio precisava criar um algoritmo que pedisse 4 notas, exibisse essas notas e mostrasse se o aluno estaria aprovado/reprovado e a média.
 Utilizei Scanner para entrada das notas e do nome do aluno;
 Estrutura de controle (if/else-if/else) para verificar se está aprovado, de recuperação ou reprovado.
 
5️⃣ - No quinto desafio foi solicitado que criasse um menu com 3 opções e exibisse um comentário sobre cada opção.
 Utilizei String como bloco de texto para criar o menu;
 Scanner para escolher a opção do menu;
 Estrutura de controle (switch/case) para quando o usuário escolha uma das opções aparece o comentário sobre a opção.

6️⃣ - O sexto desafio foi apenas um incremento do quinto desafio, onde apenas coloquei a quarta opção para que saia do programa.

7️⃣ - O sétimo desafio era para criar um algoritmo de tabuada com estrutura de repetição(while).
 Utilizei Scanner para que o usuário escolha qual número deseja ver a tabuada;
 Estrutura de repetição (while) para fazer com que o número escolhido pelo usuário vezes o contador forme o resultado.

8️⃣ - O oitavo e último desafio era para melhorar o algoritmo de média, utilizando vetores.
 Utilizei Arrays para as variáveis;
 Scanner para entrada de dados do nome;
 Estrutura de repetição(For) e Scanner para perguntar e armazenar as notas do aluno;
 Estrutura de controle(if/else-if/else) para verificar a média do aluno e ver se ele foi aprovado/reprovado ou ficou de recuperação.
